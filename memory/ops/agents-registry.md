# 🤖 Реєстр агентів KeyKey — «Аналітика 360°»
*Масштабована основа. Додати агента = додати рядок у реєстр (НЕ нова scheduled-задача). Движок-оркестратор читає реєстр і прогоняє агентів. Розрахунок на 50+ агентів.*
*Архітектура: `Аналіз/KeyKey_система_агентів_архітектура.md`. Спільний контекст: `agents-shared-context.md`.*

## Принцип масштабу (до 50+)
- **НЕ 50 scheduled-задач** (некеровано, ліміти) — а 1 движок + реєстр на N агентів.
- Кожен агент = запис: `id · домен · розклад · джерела · що робить · вихід · доступ · статус`.
- Кожен агент пише результат у `agents-shared-context.md` з тегом `[id]` → єдиний контекст, ніщо не губиться.
- Самонавчання: агент дописує патерни в базу патернів спільного контексту.
- Комунікація: агент лишає сигнал у шину; оркестратор передає релевантному агенту/домену.
- Рівні доступу виходу: `CEO` (Влад+Артем, з фінансами) · `team` (без чутливого) · `personal` (особисто людині) · `vlad` (тільки Владу).
- **🎯 Головний канал системи — група «Оркестр» (`-1004382201296`, лише Влад+Артем, підтв. 22.06):** оркестратор + критик + CEO-агент кидають туди все — повна картина з фінансами/критикою/стратегією $1М, ЄДИНИЙ виняток — особисте Влада.
- **📍 МАРШРУТИЗАЦІЯ ВИХОДІВ (рівень → канал, Влад 22.06):**
  - `CEO` (фінанси · критика · стратегія $1М · оцінки навантаження людей) → **«Оркестр»** `-1004382201296` (Влад+Артем, форум-гілки).
    🧵 **Гілки Оркестру** (пиши через `reply_to_message`, message_id=topic_id): 💰 Гроші=`2` (fin + продажі) · 🛠 Команда=`3` (team/code/projects/support) · 🌍 Ринок=`4` · 🔥 Пожежа=`5` (CEO + Критик + синтез оркестратора — серце дебатів).
  - `team` (корисне ВСІЙ команді: рух воронки без сум · статус проєктів · дедлайни · нові коміти · скарги клієнтів) → **«Ассистент KeyKey»** `-5399016122`. Влад: «агенти корисні для команди пишуть не в Оркестр, а в Ассистент».
  - `urgent` (важливе ТЕРМІНОВЕ для конкретної людини) → в **ОСОБИСТІ тій людині** (як Лері) — короткий пінг, підпис 🛰️ Асистент, лише робочі факти/дедлайни (НЕ оцінки людини, без чутливого). Влад: «термінові нагадування — пиши в особисті, як Лері».
  - `vlad` (особисте/чутливе) → Владу особисто.
- **✂️ ФОРМАТ — ПО СУТІ (Влад 22.06, «краткость — сестра таланту»):** кожен агент пише КОРОТКО — топ-3 важливе, 1 теза = 1 рядок, кожен рядок = факт+[джерело] або дія. Без води/преамбул/повторів. Критик карає за простирадла й воду нарівні з фактичними помилками. Корисні команді агенти активно публікують у «Ассистент KeyKey».

Асистент = **🛰️ Асистент** · Критик = **🔴 КРИТИК** · CEO-агент = **🎯 CEO** · доменні (через оркестратора) — свій тег (💰 fin · 📈 sales · 👥 team · 🧱 code …).

Нові канали / нові адресати / зовнішні / особисте Влада — усе одно заборонено без явного дозволу.

## Як додати агента (масштаб 50+)
1. Додати рядок у реєстр (id, домен, розклад, джерела, вихід, доступ).
2. Описати його інструкцію в `agents-prompts/` (1 файл = 1 агент).
3. Движок підхопить автоматично на наступному прогоні — нова scheduled-задача НЕ потрібна.
