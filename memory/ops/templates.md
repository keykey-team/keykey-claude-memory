# Шаблони комунікації
*Оновлено: 2026-06-08*

> Готові тексти для типових ситуацій. Адаптую під контекст — не пишу з нуля.

---

## 📨 Follow-up клієнту (після зустрічі/демо)

```
[Ім'я], дякую за зустріч.

Резюмую домовленості:
— [пункт 1]
— [пункт 2]

Наступний крок: [що робимо, хто відповідальний, до якої дати]

Якщо є питання — пишіть. Будемо на зв'язку.

З повагою,
Влад / KeyKey
```

---

## 📨 Follow-up після відправки КП (якщо мовчать)

```
[Ім'я], добрий день.

Надсилав КП [N] днів тому — хотів уточнити чи дійшло і чи є питання.

Якщо щось потребує уточнення або корекції — готовий обговорити.

Влад
```

---

## 📨 Нагадування команді (дедлайн наближається)

```
[Ім'я], нагадую — дедлайн по [задача/проєкт] [дата].

Поточний статус: [що зроблено / що залишилось]?

Якщо є блокери — скажи одразу, вирішимо.
```

---

## 📨 Структура КП (комерційна пропозиція)

```
# КП — [Назва проєкту] · KeyKey

## Що робимо
[1-2 речення: суть продукту/сервісу]

## Що входить
— [пункт]
— [пункт]
— [пункт]

## Терміни
[N тижнів / місяців]

## Вартість
[Сума] грн
Аванс: [%] · Решта: [умови]

## Чому KeyKey
— [1-2 доказових факти, не вода]

## Наступний крок
[Чітко: що робити клієнту далі]
```

---

## 📨 Відмова від проєкту (м'яко)

```
[Ім'я], дякую за довіру.

На жаль, зараз не можемо взяти цей проєкт — [коротка причина без деталей].

Якщо ситуація зміниться — повернемось до розмови. Бажаю успіху з проєктом.

Влад
```

---

## 💬 Відповідь на запит ціни (щоб не называти одразу)

```
[Ім'я], добрий день!

Щоб назвати точну цифру — потрібно розуміти обсяг. Можемо зробити короткий дзвінок на 15 хв?

Розпитаю про задачу і одразу скажу вартість і терміни.

Зручно [день] о [час]?
```
