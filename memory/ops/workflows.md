## 🏛️ Клод Консул (LLM Council Method)
*Джерело: Ole Lehmann — впроваджено 09.06.2026*

### Коли використовувати
- Стратегічні рішення (новий продукт, клієнт, зміна напрямку)
- Великі інвестиції часу або грошей
- Влад каже "/council" або "порадься сам з собою"
- Я бачу що рішення має серйозні ризики і одна відповідь недостатня

### 5 радників KeyKey

| Радник | Роль | Фокус |
|--------|------|-------|
| 🔴 Скептик | Contrarian | Що не так? Де ризики? Чому провалиться? |
| 🔵 Стратег | First Principles | Це відповідає нашому напрямку? Фундамент? |
| 🟢 Комерсант | Revenue lens | Скільки грошей і коли? Продається чи ні? |
| 🟡 Виконавець | Executor | Реально за ресурсами/людьми/часом? |
| 🟣 Клієнт | Outsider/Market | Що думає ринок? Що ми не бачимо зсередини? |

## 🔄 Проєктний цикл (від ліда до здачі)

```
1. ЛІД з'явився
   → Влад або Лера фіксує в Notion
   → Первинний дзвінок (15 хв) — розуміємо задачу

2. ОЦІНКА
   → Пучко оцінює обсяг (КП)
   → Влад погоджує фінальну ціну

3. КП відправлено
   → Чекаємо відповіді (follow-up через 3-5 днів якщо мовчать)

4. УГОДА підписана / аванс отримано
   → Задача в Notion: статус "Активна"
   → Призначається виконавець (fullstack)

5. РОЗРОБКА
   → Данила декомпозує → спринти
   → Лера контролює дедлайни
   → Клієнт отримує проміжні результати

6. ЗДАЧА
   → Тестування → правки → фінальна здача
   → Отримання залишку оплати

7. ПІДТРИМКА (якщо є)
   → Переходить в регулярних клієнтів
   → Тех. підтримка щомісячно
```

**Типові терміни:** 3-8 тижнів залежно від обсягу
**Типовий чек:** 50-130k грн (проєктні), 2-22k грн/міс (підтримка)

## 🔄 Онбординг нового клієнта

```
1. Аванс отриманий → Notion задача створена
2. Kick-off дзвінок з клієнтом (30 хв)
   → Збираємо всі матеріали: логотип, тексти, референси
3. Виконавець призначений → починає роботу
4. Проміжна демонстрація (на ~50% готовності)
5. Правки → фінальна версія
6. Здача + інструктаж клієнта
```

## 🔄 Процес найму (коли потрібен новий член команди)

```

2. Пучко шукає кандидатів
```

## 🔄 Система оцінки задач (Point)

Введена ~9 квітня 2026. Регламент оновлено 07.06.2026.

```
1 Point ≈ 1 хвилина роботи (але команді не озвучується прив'язка до хвилин)
Мета: уникнути психологічного навантаження від "жорстких хронометрів"
```

**Для чого:**
- Планування навантаження команди на день і тиждень
- Оцінка задач у зрозумілих одиницях
- Контроль фактичних трудозатрат vs оцінка
- Порівняти план/факт, знайти де "течуть" ресурси

**Шаблон задачі в Notion включає:** `Edge cases` (гострі кути: товар без варіацій, швидкий набір тексту, невалідні параметри)

| 5 | Зможемо → Анкета з питаннями + попередня оцінка клієнту; продавець створює TG-чат: клієнт + проджект + Пучко | Пучко / Продавець |

| 8 | Зум (проджект нагадує за день і за годину) | Проджект |
