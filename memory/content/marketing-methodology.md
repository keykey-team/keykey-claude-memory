# 📖 МАРКЕТИНГОВА БІБЛІЯ KEYKEY (на базі курсу BrandFather / Fedoriv)
*Джерело: повний корпус 34 конспектів + 58 уроків курсу (витягнуто 01.07.2026). Це наш маркетинговий СТАНДАРТ. Будь-яку маркетингову задачу веду по цій методології. Notion-шаблони: у хабі ONEQ.*

## 🧭 Архітектура маркетингу продукту (робоча, 4 рівні — Влад 02.07)
Практичне спрощення 7 блоків для команди. Порядок обов'язковий, кожен рівень стоїть на попередньому:
1. **Фундамент** — проблема + клієнт (кого і від чого рятуємо).
2. **Ядро** — продукт + killing feature + позиціонування (чим радикально інші).
3. **Обгортка** — меседжі + ціна від цінності + пакети.
4. **Двигун** — канали + продажі + метрики.
Реклама без фундаменту = злиті гроші, не стрибати одразу в двигун. Хаб ONEQ (`390be50aaef381d59623e24ea7709387`) структурований по цих рівнях.

## Наскрізна логіка: 7 блоків, ланцюг Емоція → Транзакція
**АВТОР → КЛІЄНТ → РИНОК → БІЗНЕС → МАРКЕТИНГ → БРЕНД → ТАКТИКА(Продажі).** Три ролі засновника: **Митець** (драйв) · **Інженер** (вміння) · **Фінансист** (ресурси). Метод GSD + 3 горизонти (тактика 1год–3міс → стратегія 3–5р → 5-річні блоки життя).

## 7 філософських тез Fedoriv
1. **Автор, не жертва.** Розділити Я / Ми / Воно (бізнес = автономна машина, не додаток до его). Вийти з «хмаринки» в чіткий квадрат.
2. **Сенс понад прибуток.** Проблема → Продукт → Профіт. Прибуток = сума «дякую» за вирішені проблеми.
3. **Продукт понад бренд (Product First).** Людям не потрібні унікальні бренди — потрібні унікальні продукти, добре брендовані. Поганий продукт + класний бренд = миттєва смерть.
4. **Простота = вищий пілотаж.** Проста ідея + простий символ + блискуче складне втілення. З 20 ідей обрати 1, іншим 19 сказати «Ні».
5. **Бренд = звичка = легалізована лінь** (шорткат, що звільняє клієнта від порівняння).
6. **Бренд = напрямок руху, не точка.** «Реклама завжди». Питати «що НЕ зміниться» (Безос) і будувати на цьому.
7. **Прагматизм: емоція за гроші**, але виправдана математично (CAC/LTV). Транзакція — єдиний момент істини. «Головний конкурент — вчорашній ти» (+30% до продукту щороку).

## 7 блоків — коротко (ідеї + фреймворки + вихід)
- **1. АВТОР:** три ролі; еволюція мотивації; фреймінг Я/Ми/Воно. → FEDORIV 21 (Автор), Матриця «Бізнес&Людяність», 5-річні блоки. Вихід: що драйвить/вмію/ресурси.
- **2. КЛІЄНТ:** JTBD («наймають» бренд на роботу); Customer Development; продукт=супергібрид. → JTBD, CJM, Design Thinking, VPD. Вихід: хто клієнт, яка проблема, що відчуває.
- **3. РИНОК:** ринок=вибір проблеми; пастка коммодіті; блакитний океан; радикальна перевага ×2/×10. → PEST, PMF Matrix, BCG-ринкова. Вихід: об'єм/динаміка/тех-виклик/емоційність ринку.
- **4. БІЗНЕС:** ROI головне; принцип ×2; правило 40% (маржа%+зростання%≥40). → P&L/Balance/CashFlow, 7S, Об'єднуюча ідея, Піраміда обіцянки. Вихід: фінсистема + шампур на 30 сек.
- **5. МАРКЕТИНГ:** не продажі, а створення нового; killing feature; 3 рівні цінності=тимчасова монополія. → JTBD-рутина, Design Thinking, CJM, VPD, продуктовий аудит (3 метафори), 12★ сервіс. Вихід: killing feature + продуктова карта.
- **6. БРЕНД:** бренд=емоція+маржа/звичка; Awareness+Атрибути; модель починається з тексту. → Мантра бренду, Модель (Хто/Чим/Куди), Піраміда обіцянки, рівні унікальності. Вихід: мантра + модель + ім'я/символ.
- **7. ПРОДАЖІ/ТАКТИКА:** транзакція=момент істини; бренд-імідж+перформанс; бюджет 3–5%; CAC/LTV завжди; охоплення×частота (мін 3). → CAC, LTV, 5 питань комунікації. Вихід: CAC/LTV + план комунікації.

## Фреймворки (стисло — деталі відтворюю при застосуванні)
- **FEDORIV 21 питання** — головний вхідний аудит (7 блоків × 3 виміри). Автор: 6 питань Митця (що драйвить, що робив би з безмежними грошима, надихає, емпатія, пишаюся, як зміню світ) + 5 Інженера (експертність, технології, унікальне вміння, що можу створити, таланти) + 5 Фінансиста (масштаб грошей, інвестиції, зв'язки, ринкова перевага, масштаб фінансування). Далі по блоку: Клієнт (хто/проблема/JTBD/що відчуває), Ринок (об'єм/динаміка/тех-виклик/емоційність), Бізнес (ROI/системи), Маркетинг (продукти VPD/CJM), Бренд (позиціонування/цінності/BHT/TOM/NPS), Тактика (як продати зараз/CRM/DATA/CAC-LTV). Порожні клітинки = зони ризику.
- **Матриця «Бізнес & Людяність»** — 5 аспектів «Бізнес» (математика, стратегія, процеси, планування, дисципліна) + 5 «Людяність» (ідеї, мрії, емпатія-клієнти, емпатія-команда, митець-емоції), оцінка 1–10. Середні A/B → діагноз перекосу → 3 SMART-кроки на 90 днів.
- **5-річні блоки** — життя на 5-10-15р; місія блоку; перевіряти рішення «чи відповідає місії блоку». Аналіз минулих + деталізація найближчого (цілі/ринки/продукти/ресурси/відмови) + щорічний аудит.
- **Об'єднуюча ідея (шампур)** — 3 питання: Хто я? / Чому я? / Куди я? 3 критерії: магнетичність + унікальність + кристальна чистота. Ліфт-тест 30 сек. Правило 20 ідей.
- **PEST** — Political/Economical/Social/Technological тренди що підіймають/вбивають ринок.
- **PMF Matrix** — Вміння×Потреба: Старт / Зона успіху / Зона ризику (добре роблю НЕ те що треба) / Інновація. Назад із «вже не треба» шляху немає — обнулятися в новій ніші.
- **BCG-ринкова** — Червоний/Блакитний океан; 3 стадії тяги (весла/двигун-перформанс/вітрила-народна любов); 4 стадії підприємця (їжачок→авторський→індустріальний→інвестор).
- **P&L (водоспад) / Balance (дзеркало інвестицій) / Cash Flow (каса)** — три кити. Норми: маржа 20% норма/30%+ висока; зростання р/р 20%/30%+; правило 40%; ×2 до депозиту; доходи ростуть швидше витрат ×1.5.
- **McKinsey 7S** — Strategy/Structure/Systems (hard) + Values/Style/Staff/Skills (soft). Спрощено: Purpose-Product-People-Profit.
- **JTBD** — «В момент X хочу прогресу Y, наймаю бренд Z замість альтернатив». 3 рівні: функціональний/емоційний/соціальний (лише функція = зона ціни; емоція+соц = маржа).
- **CJM** — карта шляху клієнта; стани: ага/вау/pain point (→drop point). Знайти болі → продуктові рішення. «Малі бар'єри вбивають великі транзакції».
- **Design Thinking** — Discovery(біль) → Прототип(за тиждень) → Тест → Масштаб. «Помиляйтеся швидше, дешевше».
- **VPD (Value Proposition Canvas)** — профіль клієнта (jobs/pains/gains) × карта цінності. ПРАВИЛО: цитати клієнта НЕ редагувати (з матом — з матом).
- **Мантра бренду / Модель** — Хто/Чим/Куди; масштаб слово→фраза→абзац→сторінка→книга; пташка-довбач (одна ідея роками); ліфт-тест; захист від вакууму (не сформулюєш — придумають за тебе).
- **Піраміда обіцянки** — «хороший бренд = перевиконана обіцянка»; сформулювати в слові/фразі/абзаці, потім стабільно перевиконувати.
- **CAC** — (бренд+перформанс бюджет за місяць)/нові клієнти. Ідеал: відбивається з 1-ї транзакції.
- **LTV** — сума за весь час клієнта. LTV/CAC — головне співвідношення. Утримання дешевше за залучення (спершу «що зробити для існуючих», потім залучення).

## Покроковий процес для НОВОГО продукту (жорсткий порядок)
0. Вхідний аудит: **FEDORIV 21** + **Матриця Бізнес&Людяність**.
1. **Автор** — 3 ролі про продукт + Я/Ми/Воно + вписати в 5-річний блок.
2. **Клієнт** — Customer Dev інтерв'ю + JTBD (3 рівні) + CJM (pain points) + VPD (реальні цитати).
3. **Ринок** — PEST + PMF Matrix + BCG-океан + тест Бренсона (30%+/×2/×10?).
4. **Бізнес** — P&L/Balance/CF + правило 40%/×2 + 7S (або Purpose-Product-Profit) + Об'єднуюча ідея + ліфт-тест + правило 20 ідей.
5. **Маркетинг** — killing feature + Design Thinking + продуктовий аудит (Ресторан/Аеропорт/Діснейленд) + 12★ сервіс.
6. **Бренд** — Модель (Хто/Чим/Куди) + Мантра + Піраміда обіцянки + рівень унікальності + ім'я/символ + дизайн-«долюбленість».
7. **Продажі/Тактика** — бюджет 3–5%/5–10% + CAC/LTV + CRM/лояльність + 5 питань комунікації + охоплення×частота + «довге/коротке світло» + паралельні тести + «реклама завжди».
8. **Цикл** — квартал: CAC/LTV + продуктовий аудит; рік: FEDORIV 21 + аудит 5-річного блоку. Продукт +30% щороку.
