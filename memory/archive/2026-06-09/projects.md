# Проєкти та бізнес-контекст KeyKey
*Оновлено: 2026-06-09*

## Поточні продукти

| Продукт | Що це | Статус | Хто веде |
|---------|-------|--------|----------|
| **Frima** | CRM для ріелторів/нерухомості | MVP майже готовий, є клієнт, дедлайн кінець червня 2026 | Пучко + Макс |
| **Onyx** | AI-агент для аналітики бізнесу через природну мову | Прототип готовий (Python), потребує рефакторингу | Влад + Льоша |
| **Keyspace** | Внутрішня CRM/операційна платформа (замість Notion/Slack) | Активно використовується, планується продаж 2-3 клієнтам | Влад + Артем |
| **UBC** | Освітня платформа (тести, мовні рівні) | Комерційне відправлено; адмінка закрита (Opus 4.7), лишилось: VPS, загрузка медіа, UX, правки Лери | Данила + команда |
| **Сайти/інтернет-магазини** | Агентська робота — поточне джерело доходу | Ongoing, ~8-9 клієнтів | Данила + Нікіта + Макс |

## Команда по проєктах
- **Frima:** Пучко (lead) + Уваровський + новий Макс
- **Onyx:** Влад (lead) + Льоша (Літовченко)
- **Keyspace:** Влад + Артем (2 рази/тиждень по 3 год)
- **Сайти/UBC:** Данила (тімлід) + Нікіта + Уваровський + Даша/Богдан (аутсорс)

## Стратегічне бачення
- **Перехід:** від агентства → продуктова компанія (сайти лишаються "годівницею")
- **Ніша:** нерухомість + HoReCa + суміжні галузі
- **Амбіція:** єдина бізнес-екосистема, доступна з першого дня, росте з клієнтом
- **Раунд:** готується angel round pitch (Київ/Львів, тема: "война і AI")
- **Фінансова ціль:** $2000/людину на місяць
- **Нове (2026-06-08):** напрямок продукту — зв'язка Notion + AI як єдине рішення (будь-хто без коду збирає продукт через AI, тренд вайбкодингу). Принцип "менше ускладнювати": готові рішення зараз, своя оптимізація — другий етап. Розширення ринку: укр. бізнеси → релокація → Європа.

## AI-стек компанії
- **Onyx** — підключається до KCRM через API, природна мова
- **Copilot/Codex** — активно в розробці (задача на 3 год → 30 хв)
- **Notion AI** — транскрибує Zoom-зустрічі автоматично
- **Планується:** AI-агенти для відповідей клієнтам (аналіз коду + запит → вижимка для Лери)
