## Модулі K-Space (MVP, 15.05.2026)
- **Воронка продаж** — коментарі в задачах, при переході в "завершено" → автостворення проєкту і замовлення
- **Проєкти** — управління задачами команди
- **Замовлення (Заказы)** — табличний вид, гнучкі фільтри, автосинхронізація оплат (ФОП/картка), автокалькуляція залишків і дебіторки, нотифікації за 3 дні до дедлайну
- **Чати** — групові Telegram-чати (чого немає в KCRM і Sitnix!), внутрішні чати, голосові, відео, створення задач з чатів
- **Планер** — організація часу
- **База клієнтів** — компанії + контакти, один контакт → кілька компаній, аналітика
- **Календар** — управління часом
- **Нотифікації** — web-push, фільтрація (оплати/чати/задачі), відмітка як прочитане
- **Ролі і доступи** — гнучка система, приховування полів по ролях (корисно для стажерів)
- **Логування** — повне логування всіх дій (чого не вистачало в Notion)
- **Автоматизація** — автостворення проєктів/замовлень, автокалькуляція ЗП, синхронізація з банком
- **AI-агенти** — для онбордингу нових користувачів залежно від ролі

## Позиціювання і ціна
- **Суть:** єдина платформа для бізнесу (CRM+ERP+чати+проєкти), росте з клієнтом
- **Конкуренти:** 1С/Microsoft/Odoo = 2.5-4 млн грн тільки на впровадження; KeyKey = доступний вхід
- **Ціна:** $20,000 (разово) АБО підписка ~$20-50/міс
- **Бізнес-ціль:** 100-500 клієнтів × $20-50/міс = стабільний базовий оборот
- **Стратегія:** KEY SPACE → ONEQ вбудований всередині → клієнт отримує AI-помічника, що знає всю платформу

## Активна фіча (червень 2026): Telegram Chat Integration
Реалізується Уваровський + Горобець (Даня). Нікіта — дизайн.

**Суть:** В розділі Чати → створити чат → підключити до Telegram (особистий або груповий). Повідомлення синхронізуються двосторонньо між KeySpace і Telegram в реальному часі через webhook.

**API схема:**
- POST /api/chats — створити чат + зареєструвати webhook
- POST /api/telegram/webhook/:chat_id — отримує апдейти від Telegram
- POST /api/chats/:id/messages — відправити повідомлення через KeySpace
- GET /api/chats/:id/messages?limit=50 — пагінація

**Frontend:** CreateChatModal (кроки: Internal/Telegram → Personal/Group → Bot token + Chat ID → Validate → Save). ChatWindow з WebSocket. Sidebar з бейджами.
